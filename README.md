# Student Performance Analysis and Prediction

## About the Project
This is a beginner-friendly Python project focused on analysing student performance and predicting marks based on study hours.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Features
- Data analysis and statistical calculations
- Data cleaning and preparation
- Data visualization using charts
- Linear Regression model
- Student marks prediction based on study hours

## Objective
To understand basic data analysis and machine learning concepts through a simple student performance prediction project.

## Learning Outcomes
- Understanding Python libraries for data analysis
- Working with datasets
- Creating visualizations
- Building a basic machine learning model
